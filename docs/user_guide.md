# Руководство пользователя

## Запуск

1. Собрать проект командой `.\scripts\build.ps1`.
2. Запустить приложение командой `java -jar .\dist\office-booking.jar`.

## Создание брони

1. Выберите ресурс в выпадающем списке.
2. Введите имя сотрудника.
3. Введите дату в формате `YYYY-MM-DD`.
4. Введите час начала и час окончания.
5. Введите количество людей и цель бронирования.
6. Нажмите "Забронировать".

## Отмена брони

1. Выберите строку в таблице.
2. Нажмите "Отменить выбранную бронь".

## Сохранение

Нажмите "Сохранить". Данные будут записаны в файл `bookings.csv` рядом с местом
запуска приложения.
