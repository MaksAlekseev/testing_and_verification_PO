# Описание намеренно внесенных дефектов

Файл предназначен для преподавателя и команды-разработчика. Команде-тестировщику
желательно выдавать его после самостоятельного тестирования методом "черного ящика".

| ID | Тип дефекта | Описание | Способ обнаружения |
| --- | --- | --- | --- |
| BUG-001 | Логический | Система позволяет создать две брони одного ресурса на пересекающееся время. | Забронировать "Переговорная A" на 10-12, затем еще раз на 11-12. |
| BUG-002 | Логический / валидация | Система принимает бронь, где час окончания меньше или равен часу начала. | Ввести начало 14 и окончание 12. |
| BUG-003 | Граничное значение | Вместимость проверяется с ошибкой на 1 человека: можно забронировать ресурс сверх лимита. | Для рабочего места указать 2 человека. |
| BUG-004 | Интерфейс / данные | Для рабочих мест в таблице отображается тип "Переговорная". | Выбрать "Рабочее место 1" и добавить бронь. |
| BUG-005 | Логический | Отмена выбранной брони удаляет первую бронь выбранного сотрудника, а не строку таблицы. | Создать две брони на одного сотрудника, выбрать вторую и нажать отмену. |
| BUG-006 | Сохранение данных | При сохранении в CSV не сохраняется поле "Цель". | Заполнить цель, сохранить, перезапустить приложение и проверить таблицу. |
