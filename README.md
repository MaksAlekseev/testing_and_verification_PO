# Тестирование и верификация ПО

Репозиторий для практических работ по дисциплине "Тестирование и верификация ПО".

Тема командного проекта: "Система бронирования переговорных комнат и рабочих мест в офисе".

## Структура

- `practice_1` - практическая работа N 1, тестирование программного продукта методом "черного ящика".
- `testing_practice_2` - практическая работа N 2, модульное и мутационное тестирование.

Каждая следующая практическая работа будет размещаться в отдельной папке `practice_N`.
