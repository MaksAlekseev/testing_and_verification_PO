# Office Booking

Учебный проект для практической работы N 1 по дисциплине "Тестирование и верификация ПО".

Тема: система бронирования переговорных комнат и рабочих мест в офисе.

## Стек

- Java 8
- Swing
- Хранение данных в локальном CSV-файле

## Запуск из исходников

Требуется JDK 8 или новее.

```powershell
.\scripts\build.ps1
java -jar .\dist\office-booking.jar
```

## Сборка EXE

Для создания `.exe` требуется JDK 14 или новее с утилитой `jpackage`.

```powershell
.\scripts\build-exe.ps1
```

После сборки исполняемый файл будет находиться в папке `dist\exe\OfficeBooking`.

## Важно для проверяющей команды

В программу намеренно внесены 6 дефектов различной природы. Они описаны в
`docs/known_defects.md`, но при тестировании методом "черного ящика" этот файл
нужно использовать только после самостоятельного прохождения тест-кейсов.
