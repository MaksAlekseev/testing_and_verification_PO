# Ручной fault injection: `calculator.py`

При автоматическом анализе калькулятора возникли ограничения совместимости используемых инструментов с Python 3.12. Для дополнительной демонстрации тестов Витя временно заменил сложение `a + b` на возврат константы `99999`.

Тест `test_add` обнаружил изменение и завершился с `AssertionError`. Затем рабочая реализация была восстановлена; отдельный повторный прогон `tests/test_calculator.py` дал **5 passed**, покрытие — **100% (10/10 операторов)**. Фактический вывод сохранён в `calculator_final_test_run.md`.

Это единичный ручной эксперимент. Он не является автоматическим мутационным запуском и не позволяет заявлять mutation score.
