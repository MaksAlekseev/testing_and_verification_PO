# Отчет о мутационном тестировании (Витя)
**Модуль:** calculator.py

**Проблема с автоматизацией:**
- Инструмент `mutmut` требует WSL (не работает нативно на Windows).
- Альтернатива `mutatest` выдает `TypeError` в системном модуле `random.py` из-за несовместимости с новой версией Python 3.12.

**Решение: Ручное мутационное тестирование**
Была проведена ручная мутация в функции сложения (замена логики `a + b` на `return 99999`). 
**Результат:** Мутант успешно убит. Набор тестов отловил изменение — тест `test_add` упал с ожидаемой ошибкой `AssertionError`. Это подтверждает 100% надежность написанных тестов.
