# BUG-NUM-001

**Название:** `last_digit` использует знак отрицательного числа.
**Модуль и версия:** `number_checks.py`, версия из GitHub `main` на 2026-10-06.
**Автор:** Катя.
**Тестировщик:** Максим.
**Вызов:** `last_digit(-123)`.
**Ожидаемый результат:** `3`.
**Фактический результат:** `7`.
**Падающая проверка:** `test_last_digit` с параметрами `(-123, 3)` из `tests/test_number_checks.py`.
**Серьёзность:** Major.
**Статус:** Open.

**Воспроизведение:** Контракт требует вернуть последнюю цифру абсолютного
значения. Текущая реализация `return n % 10` для `-123` возвращает `7`.
Проверка выполнена непосредственно на текущем исходнике в Python 3.12.14.
Pytest в среде проверяющего не установлен, поэтому полный pytest-запуск и
покрытие пока не получены.
