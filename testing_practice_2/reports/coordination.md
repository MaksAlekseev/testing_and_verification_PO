## Общий запуск

Среда: Python 3.12.5, pytest 9.1.1, pytest-cov 7.1.0. Команда:

```powershell
python -m pytest tests/test_calculator.py tests/test_list_tools.py tests/test_number_checks.py --cov=calculator --cov=list_tools --cov=number_checks --cov-report=term-missing
```

Результат: **49 passed, 2 failed**. Оба отказа относятся к `LIST-001`:
`max_number([-5, -2, -9])` и `max_number([-4])` возвращает `0` вместо
максимального отрицательного числа. Покрытие этих трёх модулей — 100% операторов
(51/51). Высокое покрытие не означает, что набор полностью проходит.
