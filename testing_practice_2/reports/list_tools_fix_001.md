# Исправление LIST-001 (автор: Артем)

**Дефект:** `max_number` возвращал `0` для списков, где все элементы
отрицательные (`max_number([-5, -2, -9])`, `max_number([-4])`).

**Причина:** в `list_tools.py` начальное значение максимума было `0`, а не
первым элементом списка. Отрицательные числа никогда не превосходили `0`.

**Исправление:** начальное значение `result = numbers[0]` (проверка пустого списка
с `ValueError` выполняется раньше и не изменилась). Остальные функции не менялись.
Также убран служебный комментарий о намеренной ошибке из docstring модуля.

**Версия с ошибкой:** коммит `ae41962` (сохранена в истории Git).

**Проверка автором** (Python 3.12.3, pytest, pytest-cov), тесты Кати без изменений:

```
python -m pytest tests/test_list_tools.py --cov=list_tools --cov-report=term-missing
22 passed; list_tools.py: 29 операторов, 0 пропущено, покрытие 100%
```
