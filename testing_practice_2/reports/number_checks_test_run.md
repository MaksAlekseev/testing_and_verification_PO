# Проверка `number_checks.py`

Автор модуля: Катя. Тестировщик: Максим.

В `tests/test_number_checks.py` находятся 24 проверки чётности,
положительности, кратности, квадрата и последней цифры. Проверены отрицательные
значения, ноль, делитель-ноль и большие целые числа.

Среда: Python 3.12.5, pytest 9.1.1, pytest-cov 7.1.0.

Команда:

```powershell
python -m pytest tests/test_number_checks.py --cov=number_checks --cov-report=term-missing
```

Результат после исправления Кати: **24 passed**, покрытие операторов —
**100% (12/12)**. Исправление `last_digit` проверено: функция возвращает
последнюю цифру абсолютного значения, включая отрицательные аргументы.

Мутационный анализ MutPy 0.6.1 установлен и запускался через pytest и unittest
совместимость-обёртку. Результат инструмента оказался недостоверным: MutPy
показывал 0 покрытых узлов и 0% мутационного счёта, при этом все 12 мутантов
помечал выжившими, включая замену `%` на `*` в `is_multiple`, которая должна
ломать существующие проверки. Поэтому этот запуск не считается валидным
мутационным результатом и его счёт не приводится как результат работы.
Нужен повторный запуск совместимым инструментом/окружением и оформление
фактических результатов до и после усиления тестов.
