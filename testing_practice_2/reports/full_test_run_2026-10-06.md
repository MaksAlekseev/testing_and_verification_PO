# Общий запуск модульных тестов — 6 октября 2026

**Среда:** Windows, Python 3.12.5, pytest 9.1.1, pytest-cov 7.1.0.
Пакеты установлены в локальное окружение `.venv312` из `requirements.txt`.

**Команда из папки `testing_practice_2`:**

```powershell
python -m pytest tests/test_calculator.py tests/test_list_tools.py tests/test_number_checks.py --cov=calculator --cov=list_tools --cov=number_checks --cov-report=term-missing
```

**Результат:** 48 тестов прошли, 3 упали из 51.

- `calculator.py`: все 5 pytest-тестов прошли.
- `list_tools.py`: 20 из 22 прошли; два провала относятся к `max_number` на
  списке только из отрицательных чисел и на одноэлементном отрицательном списке.
  Они соответствуют открытому `LIST-001`.
- `number_checks.py`: 23 из 24 прошли; `last_digit(-123)` вернула 7 вместо 3,
  открыт `BUG-NUM-001`.
- Покрытие операторов калькулятора, списков и проверки чисел составило 100%
  (51/51 операторов). Полное покрытие операторов не означает, что требования
  выполнены: три проверки упали.
- Тесты для `text_tools.py` отсутствуют, поэтому модуль не запускался и его
  покрытие не измерялось.

Мутационные запуски не проводились. Перед ними необходимо закрыть дефекты,
получить зелёный базовый прогон для каждого модуля и загрузить тесты строкового
модуля.
