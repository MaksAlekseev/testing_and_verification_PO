# Контракт модуля проверки чисел

**Автор:** Катя  
**Файл реализации:** `number_checks.py`  
**Язык и версия:** Python 3.12.x  
**Область входных данных:** целые числа. Другие типы находятся вне контракта.

Все функции возвращают результат и не печатают его.

| Функция | Назначение | Результат |
|---|---|---|
| `is_even(n)` | Проверяет чётность целого числа | `True`, если число чётное, иначе `False` |
| `is_positive(n)` | Проверяет, строго ли число больше нуля | `True` для положительного числа; для нуля и отрицательных чисел — `False` |
| `is_multiple(n, k)` | Проверяет, делится ли `n` на `k` без остатка | `True` при делении без остатка, иначе `False`; знак чисел не меняет правило |
| `square(n)` | Возводит целое число в квадрат | Целое число `n * n`; результат неотрицательный |
| `last_digit(n)` | Находит последнюю цифру абсолютного значения числа | Целое число от 0 до 9; например, для `-123` результат равен `3` |

## Граничные случаи и исключения

- Ноль считается чётным.
- Ноль не считается положительным.
- Для `is_multiple(n, 0)` вызывается `ValueError`.
- Ноль кратен любому ненулевому целому числу.
- `square(0)` возвращает `0`; квадрат отрицательного числа положителен.
- `last_digit(0)` возвращает `0`; для отрицательных чисел учитывается абсолютное значение.
- Для очень больших целых чисел применяются обычные правила целочисленной арифметики Python без ограничения размера.

Этот контракт описывает ожидаемое поведение и не указывает место возможного дефекта в переданной тестировщику версии.
