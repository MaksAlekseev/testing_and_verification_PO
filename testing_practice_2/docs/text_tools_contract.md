Контракт модуля обработки строк

Автор: Витя
Файл реализации: text_tools.py
Язык и версия: Python 3.12.x
Область входных данных: строки (str). Другие типы находятся вне контракта.
Все функции возвращают результат и не печатают его.
| Функция | Назначение | Результат |
|---|---|---|
| `reverse_text(text)` | Переворачивает строку задом наперед | Строка, символы которой идут в обратном порядке |
| `count_vowels(text)` | Считает количество английских гласных (a, e, i, o, u) | Целое число — количество найденных гласных |
| `is_palindrome(text)` | Проверяет, читается ли строка одинаково в обоих направлениях | `True`, если строка палиндром, иначе `False` |
| `count_words(text)` | Считает количество слов, разделенных любыми пробельными символами | Целое число — количество слов |
| `remove_spaces(text)` | Удаляет из текста обычные пробелы | Строка без символов обычного пробела `" "` |
Граничные случаи и исключения

Для reverse_text("") пустая строка возвращает пустую строку.

В count_vowels(text) регистр не учитывается (например, 'A' и 'a' считаются одинаково).

В is_palindrome(text) регистр символов полностью игнорируется, но пробелы и знаки препинания учитываются и строго влияют на результат (например, "А б а" и "Аба" — разные строки).

Для count_words(text) слова разделяются любыми пробельными символами (обычные пробелы, табуляция \t, переносы строк \n). Если строка пустая или состоит исключительно из пробельных символов, возвращается 0.

В remove_spaces(text) удаляются исключительно обычные пробелы " ". Другие пробельные символы (например, \n или \t) остаются в строке без изменений.

Этот контракт описывает ожидаемое поведение и не указывает место возможного дефекта в переданной тестировщику версии.
