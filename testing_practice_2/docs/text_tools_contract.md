Описание функций и ожидаемое поведение:

reverse_text(text: str) -> str
Возвращает перевернутую строку.
Граничные случаи: Для пустой строки возвращает пустую строку.

count_vowels(text: str) -> int
Считает количество английских гласных (a, e, i, o, u) в строке.
Ожидаемое поведение: Регистр не учитывается (например, A и a считаются).

is_palindrome(text: str) -> bool
Проверяет, является ли строка палиндромом (читается одинаково слева направо и справа налево).
Ожидаемое поведение: Регистр символов полностью игнорируется. Пробелы и знаки препинания учитываются и являются частью проверяемой строки.

count_words(text: str) -> int
Считает количество слов в тексте.
Ожидаемое поведение: Слова разделяются любыми пробельными символами (пробелы, табуляция, переносы строк).
Граничные случаи: Если строка пустая или состоит только из пробельных символов, возвращает 0.

remove_spaces(text: str) -> str
Удаляет из строки исключительно обычные пробелы " ".
Граничные случаи: Другие пробельные символы (например, \n или \t) остаются в строке без изменений.
