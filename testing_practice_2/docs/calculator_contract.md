# Контракт `calculator.py`

Модуль принимает целые или вещественные числа. Функции возвращают результат
и не печатают его. Каждая функция проверяет одну арифметическую операцию.

| Функция | Ожидаемое поведение | Примеры |
|---|---|---|
| `add(a, b)` | Возвращает сумму `a + b`. | `add(2, 3) == 5` |
| `subtract(a, b)` | Возвращает разность `a - b`. | `subtract(2, 3) == -1` |
| `multiply(a, b)` | Возвращает произведение `a * b`. | `multiply(2, 3) == 6` |
| `divide(a, b)` | Возвращает частное `a / b`. При `b == 0` вызывает `ZeroDivisionError`. | `divide(6, 2) == 3`; `divide(1, 0)` вызывает исключение |
| `absolute_value(number)` | Возвращает абсолютное значение: результат неотрицательный и равен расстоянию числа от нуля. | `absolute_value(-4) == 4`; `absolute_value(3) == 3` |

Проверить стоит положительные и отрицательные значения, ноль, смешение целых
и вещественных аргументов, а также деление на ноль. Для приближённого
сравнения вещественных результатов используйте `pytest.approx`.
