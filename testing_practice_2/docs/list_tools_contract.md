# Контракт модуля `list_tools.py`

**Автор:** Артем  
**Тестировщик:** Катя  
**Файл реализации:** `list_tools.py`  
**Язык и версия:** Python 3.12.x  
**Область входных данных:** список (`list`) целых или вещественных чисел.
Другие типы элементов находятся вне контракта.

Все функции возвращают результат и не печатают его. Ни одна функция не
изменяет переданный список.

| Функция | Назначение | Результат |
|---|---|---|
| `sum_numbers(numbers)` | Сумма всех элементов списка | Число; для пустого списка — `0` |
| `max_number(numbers)` | Наибольший элемент списка | Элемент списка с максимальным значением |
| `min_number(numbers)` | Наименьший элемент списка | Элемент списка с минимальным значением |
| `count_even(numbers)` | Количество чётных элементов | Целое число `>= 0`; для пустого списка — `0` |
| `reverse_numbers(numbers)` | Список в обратном порядке | **Новый** список; для пустого списка — `[]` |

## Граничные случаи и исключения

- Пустой список: `sum_numbers([]) == 0`, `count_even([]) == 0`,
  `reverse_numbers([]) == []`.
- Пустой список: `max_number([])` и `min_number([])` вызывают `ValueError`.
- Список из одного элемента: максимум и минимум равны этому элементу,
  `reverse_numbers([x]) == [x]`.
- Отрицательные числа, ноль и повторяющиеся значения обрабатываются по
  обычным математическим правилам. Например, `max_number([-5, -2, -9]) == -2`.
- Ноль и отрицательные чётные числа считаются чётными: `count_even([0, -2, -3]) == 2`.
- `reverse_numbers` возвращает новый объект списка, а не исходный. Исходный
  список после вызова остаётся без изменений.
- Во всех функциях исходный список сохраняет содержимое и порядок элементов.

## Примеры

```python
sum_numbers([1, 2, 3])        # 6
max_number([3, 7, 2])         # 7
min_number([3, 7, 2])         # 2
count_even([1, 2, 3, 4])      # 2
reverse_numbers([1, 2, 3])    # [3, 2, 1]
```

Этот контракт описывает ожидаемое поведение и не указывает место возможного
дефекта в переданной тестировщику версии.
