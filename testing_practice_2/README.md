# Практическая работа № 2 — модульное и мутационное тестирование

Командная работа на Python 3.12.x: разработаны четыре небольших модуля, для каждого подготовлены контракт и независимые pytest-тесты. Дефекты, найденные при перекрёстном тестировании, исправлены и перепроверены.

## Состав проекта

- `calculator.py`, `list_tools.py`, `number_checks.py`, `text_tools.py` — проверяемые модули.
- `tests/` — pytest-наборы для четырёх модулей.
- `docs/*_contract.md` — контракты ожидаемого поведения.
- `reports/` — итоговые результаты запусков, закрытые баг-репорты и анализ мутаций.
- `requirements.txt` — версии инструментов.

## Установка и запуск

Из этой папки выполните в PowerShell:

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
python -m pytest --cov=calculator --cov=list_tools --cov=number_checks --cov=text_tools --cov-report=term-missing
```

Найденные при перекрёстном тестировании дефекты исправлены и закрыты; детали и подтверждения повторных запусков приведены в соответствующих отчётах.

## Мутационный анализ

| Модуль | Результат | Инструмент и пояснение |
|---|---:|---|
| `calculator.py` | 1 ручная мутация обнаружена тестом сложения | Это демонстрационный ручной fault injection, не автоматический mutation score. |
| `list_tools.py` | 13 из 15 уничтожены; 2 эквивалентные мутации выжили | pytest-gremlins; равные экстремальные значения не различимы по контракту. |
| `number_checks.py` | 22 из 22 уничтожены | pytest-gremlins. |
| `text_tools.py` | 21 из 21 уничтожены полным набором | Cosmic Ray; отчёт отдельно описывает контрольный запуск с сокращённым набором. |

MutPy 0.6.1 не дал достоверного результата в Python 3.12. Поэтому для числового и спискового модулей применён pytest-gremlins, для строкового — Cosmic Ray. Инструментальные ограничения и границы интерпретации указаны в отчётах мутационного анализа.
