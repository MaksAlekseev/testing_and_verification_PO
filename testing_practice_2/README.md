# Практическая работа № 2

Модульное и мутационное тестирование. Общая среда команды: **Python 3.12.x**.

## Участники и обмен

| Участник | Разрабатывает | Проверяет |
|---|---|---|
| Максим | `calculator.py` | `number_checks.py` Кати |
| Витя | `text_tools.py` | `calculator.py` Максима |
| Артем | `list_tools.py` | `text_tools.py` Вити |
| Катя | `number_checks.py` | `list_tools.py` Артема |

Разработчик передаёт тестировщику код и этот контракт. Тестировщик пишет
тесты, запускает их и оформляет найденный дефект. Разработчик исправляет его
после получения баг-репорта, затем тестировщик повторно запускает весь набор.
Место преднамеренной ошибки автор заранее не сообщает.

## Структура

- `calculator.py` — модуль Максима.
- `tests/` — тесты модулей, добавляются назначенными тестировщиками.
- `docs/calculator_contract.md` — контракт калькулятора.
- `docs/TEAM_GUIDE.md` — общий план и отдельные инструкции участникам.
- `docs/AI_AGENT_TASKS.md` — готовое ТЗ для ИИ-агентов команды.
- `reports/coordination.md` — общий статус этапов и шаблон баг-репорта.
- `requirements.txt` — инструменты команды.

## Настройка

Установите Python 3.12.x. В Windows используйте `py -3.12` вместо `python`,
если команда `python` не находит установленную версию.

```powershell
py -3.12 -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

## Команды проверки

```powershell
python -m pytest --cov=. --cov-report=term-missing
```

Для MutPy пример запуска модуля с тестами через экспериментальный pytest runner:

```powershell
mut.py --target calculator --unit-test tests.test_calculator --runner pytest -m
```

После настройки Максим должен проверить эти команды на своей машине и сообщить
команде фактические версии и вывод. В документации MutPy runner для pytest
помечен экспериментальным; если команда не работает в общей среде, не
записывайте мутационные результаты как выполненные — сначала согласуйте
совместимый инструмент и способ запуска с командой/преподавателем.
